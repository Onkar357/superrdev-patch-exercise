# Required handwritten explanations

Before submitting, add clear photos or scans of your own handwritten explanations to this folder.

For each bug fixed, explain:
1. File/layer where the bug was found.
2. How you discovered it.
3. Root cause.
4. What changed and why.

This README is only a reminder; it does not replace the required handwritten photos.
