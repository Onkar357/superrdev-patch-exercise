# Patch Notes

## Summary of changes
- Grouped the title/description search predicates so the archived-task exclusion and optional status filter apply to every matching row. Updated both the H2 query reference and Oracle reference artifact to stay consistent.
- Added validation for page and pageSize, capped pageSize at 100, and return a clear 400 response for unsupported status values.
- Removed the artificial sleep from the API request path.
- Reset pagination when search or status changes. Added request cancellation and reliable loading/error-state cleanup so stale requests do not replace newer results.

## What I chose not to change
I did not redesign the app, add new endpoints, or introduce authentication because those changes are outside the focused search/filter bug fixes and would increase the patch size.

## Biggest remaining risk
The repository still loads all matching tasks into application memory before slicing a page. For a large production dataset, database-level pagination and a count query would be more efficient.
